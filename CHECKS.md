# Результати перевірки

Пройдено 195 автоматичних перевірок без помилок:
- HTML5-синтаксис усіх чотирьох завдань через html5lib.
- Синтаксис CSS і декларацій через tinycss2.
- Локальні посилання HTML/CSS та зображення існують; ідентифікатори унікальні; якорі меню мають цілі.
- Рівно 3 абзаци й 2 div, кожен по 50 слів у завданні 1.
- Значення всіх заданих стилів завдання 1 після каскаду правил.
- Наявність рецепта і дев’яти рядків продуктів.
- Кольори головних і вкладених посилань меню, квадрати ягід, піктограми овочів, відсутність звичайних маркерів фруктів, відсутність підкреслення ягід.
- Чотири нумеровані пункти по 50 слів, list-style-position:inside.
- Кожен з 11 комбінаторів завдання 4 перевірений через cssselect2: набір вибраних елементів збігається з незалежним очікуваним набором, визначеним XPath.
- Властивості потрібних елементів перевірено після каскаду правил; контрольні span залишаються без додаткових стилів.
- У завданні 4 немає вкладених p і зламаних src="#".

Усі чотири сторінки додатково відрендерені WeasyPrint та візуально переглянуті. Результат звірено з вимогами та зразками PDF. Перший абзац завдання 1 навмисно не переноситься, а другий div має великі інтервали згідно з умовою.

Обмеження перевірки: це статична перевірка та рендер WeasyPrint. Chromium не вдалося завантажити в середовищі, тому запуск саме у Chrome/Safari тут не перевірений. Сторінки використовують звичайні HTML/CSS без JavaScript і зовнішніх залежностей.

Завантаження до особистого GitHub не виконувалось: адресу цільового репозиторію не вказано. Команди наведено в README.md.
